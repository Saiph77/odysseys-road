# 《归航 / NOSTOS》60 秒连续剧本

这一目录把当前路演版拆成两份可独立制作、又能在 `20.0s` 无缝衔接的脚本。

## 阅读顺序

1. [`01_OPENING_AND_SELECTION_SCRIPT.md`](01_OPENING_AND_SELECTION_SCRIPT.md)
   `00.0–20.0s`：特洛伊陷落、守城神像断首、火海转为平静海面、三面神谕镜选择 Track。
2. [`02_TRACK_3_AND_HOMECOMING_SCRIPT.md`](02_TRACK_3_AND_HOMECOMING_SCRIPT.md)
   `20.0–60.0s`：塞壬、斯库拉与卡律布狄斯、太阳神的牛、晴空雷击、漂流与伊萨卡归乡。

## 一分钟连续结构

```text
00–10s  木马入城 → 焚城 → 雅典娜守城神像断首 → 裂缝成为海平线
10–20s  三面神谕镜 → 关注累计 → 命运确认 → Track 3 声波出镜
20–30s  塞壬：用头部混合“归乡”与“荣光”两种歌声
30–40s  两种死亡：向左看漩涡，向右看斯库拉
40–50s  太阳神的牛：勿视、勿触 → 落日 → 篝火 → 黎明
50–60s  晴空雷击 → 视觉残留 → 风暴 → 断桅漂流 → 伊萨卡
```

## 当前范围口径

- 当前第一版只制作 Track 3 的正式剧情。
- 交互测试模式允许 Track 1/2 真实获得最高关注并完成镜面转场，但终点只是“这段记忆尚未归来”的占位页。
- 正式 60 秒路演若必须保证完整演完下篇，可只让 Track 3 获得最终确认；另外两镜仍保留关注和浏览反馈。
- 两份文档均为剧本、声音、美术与交互设计，不代表对应功能或素材已经实现。
